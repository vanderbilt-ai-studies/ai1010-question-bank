**Question:** A student asks a model for ten slogan ideas, runs the same prompt several times, and keeps getting nearly the same list. Based on the lecture, what would give more variety between runs?

- A. Start each attempt in a new chat, so the model has a clean slate
- B. Lower the temperature, so the model weighs more options before choosing
- C. Raise the temperature, so more noise is added when each token is chosen
- D. Ask for fifty slogans instead of ten, so the model has to reach further

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. A fresh chat changes what is in the context, which can change the answer, but from the same prompt the model would still take much the same path. What varies a run is the noise added when each token is chosen.
- B. Not quite. Lower temperature does the opposite: with less noise the top token wins nearly every time and the model retraces the same path. That is what you want for a form letter, not for brainstorming.
- C. Correct. With more noise at the choice step, a token that was not quite the top choice sometimes wins, and because each chosen token becomes context, the paths diverge from there. That is the exploring the lecture described.
- D. Not quite. A longer list does push past the most obvious ideas within one answer, but nothing in the mechanism changes. How much the model wanders between runs is set by the noise at the choice step.
