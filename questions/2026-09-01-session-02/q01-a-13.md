**Question:** The lecture called context the single most important lever you have. Why does context deserve that title?

- A. Because everything the model works from arrives through it
- B. Because a longer context always makes the model produce a longer answer
- C. Because context changes the model's parameters a little with every message
- D. Because the numbers assigned to tokens depend on how much context there is

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Your prompt, your attachments, and the conversation so far all enter at the left of the pipeline, and the model's parameters do not change from one request to the next. So the context is the one thing that varies between requests, and you are the one who decides what is in it.
- B. Not quite. Context length does not set answer length; the model still produces one token at a time. Context matters for what the model can draw on, not for how much it says.
- C. Not quite. Nothing you type alters the model's weights. Context is read, not learned from, which is exactly why it is the lever you can pull without retraining anything.
- D. Not quite. A token's vocabulary number is fixed regardless of what surrounds it. Context matters because the model responds to what is in it, not because it changes the encoding.
