**Question:** Ten messages into a conversation, the model correctly refers back to something you mentioned at the start. What explains this?

- A. The token encodings remember earlier turns of the chat
- B. The model saved its token probabilities from the earlier messages
- C. Attention kept your earlier remark in memory between the turns
- D. The conversation so far is part of the context sent to the model

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. Encoding is a stateless lookup that turns a token into a number. It has no memory of what came before.
- B. Not quite. Probabilities are computed fresh on each run and are not stored between messages. The model does not carry them forward.
- C. Not quite. Attention has no memory of its own; on each run it works only over the tokens in front of the model. Your remark is available because the whole conversation is sent again as context, not because anything was held over.
- D. Correct. Context is not just your latest message; it includes the whole conversation to that point. Your earlier remark went into the model along with the newest message, so the model could work from it.
