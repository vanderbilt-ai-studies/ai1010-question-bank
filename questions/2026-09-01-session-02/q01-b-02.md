**Question:** What is the name for generating a response one token at a time, feeding each new token back into the context before producing the next?

- A. Self-supervised learning
- B. Autoregressive generation
- C. Token encoding
- D. Attention

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. Self-supervised learning is how the model was trained: hide the next word, guess it, adjust. The token-by-token loop at response time is a different idea with its own name.
- B. Correct. The "auto" is the model feeding on its own output: each token it produces becomes part of the context that shapes the token after it. That loop is what turns a one-token machine into a paragraph writer.
- C. Not quite. Token encoding is the step where text is chopped into tokens and each is replaced by its vocabulary number. It happens on the way into the model, not in the loop that produces the response.
- D. Not quite. Attention is a mechanism inside each decoder stack, working on the tokens already in the context. It is not the name for the outer loop that appends each new token and runs the model again.
