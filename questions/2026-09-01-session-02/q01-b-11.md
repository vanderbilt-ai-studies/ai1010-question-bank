**Question:** Partway through an answer, a model picks a slightly unusual word. Why does that one choice matter for everything the model writes afterward?

- A. The word joins the context, so every later token is predicted with it in view
- B. It does not matter, because each token is predicted from the original prompt alone
- C. The model goes back and revises the earlier word if later tokens do not fit it
- D. The model restarts from the prompt whenever it produces a word it did not expect

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Nothing the model produces is thrown away. Each chosen token is appended and fed back, so an unusual word early on tilts every prediction that follows it.
- B. Not quite. If tokens were predicted from the prompt alone, the response could not stay coherent with itself. The model sees its own earlier output every time it runs, which is what autoregression means.
- C. Not quite. There is no going back. Once a token is produced it is part of the context for good, so the model has to make the rest of the response fit the word, not the other way round.
- D. Not quite. The model does not judge its own output as expected or unexpected. It simply appends whatever it chose and keeps walking from there.

</details>
