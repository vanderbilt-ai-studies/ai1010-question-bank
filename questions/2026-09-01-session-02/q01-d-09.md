**Question:** A student pastes a report into a chat and gets accurate answers about it. The next day she opens a fresh chat, asks about the same report without pasting it, and the answers are wrong. What explains the change?

- A. The report was in the context the first time and is not in the context now
- B. The model forgot the report because too much time passed between the chats
- C. The model learned the report on the first day and then unlearned it
- D. The second chat was served by a smaller model with fewer parameters

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Everything the model works from has to be in front of it on this run. Attention could read the report while it sat in the context; in a new chat there is nothing there to read, so the model falls back on its fuzzy picture of the world.
- B. Not quite. Time has nothing to do with it. Nothing from the first chat was ever held, so there was nothing to fade; the context is assembled fresh for every request.
- C. Not quite. Nothing you paste changes the model's parameters, so there was no learning to undo. The document mattered only while it sat in the context.
- D. Not quite. The largest model available would do the same. Without the report in the context, no number of parameters supplies a document the model has never been shown.
