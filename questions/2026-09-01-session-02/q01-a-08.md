**Question:** What happens at the token encoding stage of the pipeline?

- A. Each token is placed at a location in a high-dimensional semantic space
- B. The text is scrambled so that the company running the model cannot read it
- C. The model computes a probability for each possible next token
- D. The text is cut into tokens, each with a vocabulary id number

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. That is the token embedding stage, which comes next. Encoding happens first and is simpler: it only assigns each token an id number from the vocabulary.
- B. Not quite. The word 'encoding' sounds like encryption, but it is not about secrecy. It is bookkeeping: each token is swapped for its number in a fixed vocabulary so the model has numbers to work with.
- C. Not quite. Probabilities appear at the far right of the pipeline, after the decoder stacks. Encoding is the very first step after the context, before the model has done any thinking at all.
- D. Correct. Deep learning models handle numbers and nothing else, so the first thing done to your text is to break it into tokens and look each one up in a fixed vocabulary. What comes out is a list of id numbers; meaning enters one step later, at the embedding stage.
