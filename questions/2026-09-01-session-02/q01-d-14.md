**Question:** The lecture says the bad news about hallucination is that hallucinating is all the model ever does. What point is being made?

- A. That the model cannot be trusted for any task and should not be used
- B. That the model hallucinates far more often than most people notice
- C. That a right answer and a wrong one come from the identical process, with no truth mode
- D. That the model produces random text and only sometimes lands on sense

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. The line is not a warning against using models; the rest of the course is about using them well. It is a description of the mechanism: the output is always a plausible continuation, so getting truth out of it depends on what you put in.
- B. Not quite. The claim is not about frequency at all. It is that there is no second mode the model switches into when it is right; the process that produces a wrong answer is the same one that produces a right one.
- C. Correct. The model always produces a probable continuation; that is its whole job. A correct answer is the case where the plausible thing happened to be true, usually because the context or a sharp part of the JPEG supplied it.
- D. Not quite. The output is far from random; it is the most probable continuation with a little noise added. The point is that probable is not the same as true, not that the model is guessing blindly.
