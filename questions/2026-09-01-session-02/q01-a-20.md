**Question:** According to the lecture, how is a language model trained?

- A. Engineers write rules of grammar and lists of facts and load them into the model
- B. The model reads a dictionary and a grammar book before it sees any other text
- C. The model memorizes the training text so that it can look passages up later
- D. The model guesses each hidden next word and is adjusted when it is wrong

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. That is how expert systems were built, and it is not how this works. No rules or fact lists are written down; the model has to pick them up on its own in order to guess well.
- B. Not quite. There is no dictionary stage. Meaning and grammar are learned from the same next-word guessing as everything else.
- C. Not quite. The model has no stored text to consult. Training adjusts parameters after each guess; it does not file the text away.
- D. Correct. That loop is the whole recipe, run trillions of times: guess, compare with the word that was actually there, nudge the parameters, move on. Everything the model knows about grammar, meaning, and the world comes out of doing that at enormous scale.
