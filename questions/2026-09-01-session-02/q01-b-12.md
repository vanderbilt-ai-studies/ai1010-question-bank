**Question:** A model's reply comes to about 300 tokens. Roughly how many times did the whole model run to produce it?

- A. Once, because a single pass produces the entire reply
- B. Twice, once to read the prompt and once to write the reply
- C. About a dozen times, roughly once per sentence
- D. About 300 times, once for each token

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. A single pass produces a single token, not a reply. Getting 300 tokens out of a one-token machine takes the loop of appending and re-running.
- B. Not quite. Reading and writing are not separate phases. Every run reads the whole context, including the prompt, and writes exactly one token.
- C. Not quite. Sentences are not the model's unit of work. Each run yields one token, so the count of runs tracks tokens, not sentences.
- D. Correct. The model runs once per token, and each run takes the whole context, now one token longer. That is why a long reply takes noticeably longer than a short one.
