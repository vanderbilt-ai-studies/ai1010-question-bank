**Question:** Why can a document placed in the context override what the model learned in training?

- A. Because the context is written into the MLP (multi-layer perceptron) alongside the training data
- B. Because attention reads the context, which can outweigh a blurry memory in the weights
- C. Because the model briefly retrains itself on any document you upload
- D. Because documents in the context are checked for accuracy before the model reads them

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. The MLP is fixed after training and nothing you type is written into it. The context enters through attention, which is a different path, and that path can carry evidence the MLP's fuzzy picture does not have.
- B. Correct. Attention looks back over every token in the context, so a document you paste is directly available when the representation is built. The MLP then nudges from a lossy picture of the world, and sharp evidence in context can override a blurry memory.
- C. Not quite. No training happens during a chat; the parameters do not move. The document works because attention reads it as part of the context, not because the model has learned it.
- D. Not quite. Nothing checks the context for truth; a wrong document in the context can override a right memory just as easily. What matters is that context is the evidence attention can draw on, whatever its accuracy.
