**Question:** Up to the point where the token probabilities are produced, how does the model behave from one run to the next?

- A. Randomly, because the embeddings start from a fresh position each run
- B. Randomly, because attention samples which earlier tokens to look at
- C. Deterministically, so a repeated context produces the identical spread of probabilities
- D. Deterministically, but only when no noise is added at the choice step

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. Embeddings are learned during training and then fixed; a token lands in the same location every time. Nothing before the probabilities is random, which is why the variation has to be added on purpose at the end.
- B. Not quite. Attention computes a weighted average over every earlier token; it does not sample a subset. The whole path from context to probabilities is a fixed computation with no dice in it.
- C. Correct. Everything from token encoding through the last decoder stack is a fixed calculation, so identical context gives identical probabilities. The variety you see in answers is introduced afterward, when noise is added at the choice step.
- D. Not quite. Noise is added after the probabilities exist, so it cannot reach back and change them. The stages before the choice compute the same way whether or not noise is applied later; only which token gets picked varies.
