**Question:** What is the one-line definition of an agent given at the close of the session?

- A. A model plus a much bigger context window
- B. Tools plus autonomy
- C. A large model and a small model working together
- D. Memory plus a task list

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. A large context helps, but it is only part of what the agent's context holds. The definition hinges on what the model can do, not on how much it can read.
- B. Correct. An agent is a model that can call tools and has the freedom to keep looping until the job is done. Everything else in the picture, the working space, documents, memory, and skills, is the harness that supports that.
- C. Not quite. The size of the model is not what makes something an agent; a single model of any size can be one. What matters is that it can act through tools and decide to keep going.
- D. Not quite. Memory and task lists are parts of the harness around the model, not the definition. They support an agent, but the defining pair is tools and autonomy.
