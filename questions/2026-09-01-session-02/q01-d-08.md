**Question:** How can a small amount of noise at the moment of choosing a token lead to two whole answers that differ, rather than one word here and there?

- A. The noise is added to every embedding, so the meaning of the prompt itself shifts
- B. Each chosen token joins the context, so one different choice steers every choice after it
- C. The model drafts the entire answer several times and returns a different draft each time
- D. The noise changes which stored answer the MLP (multi-layer perceptron) retrieves

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. The embeddings and everything up to the probabilities are fixed; the noise enters only at the choice step. What makes it spread is not a changed prompt but the fact that each choice is fed back into the context.
- B. Correct. Generation is autoregressive: the token just chosen is appended to the context and the whole model runs again. A slightly different word early on changes the context for the next word, and the paths diverge from there.
- C. Not quite. The model never holds several finished drafts; it produces one token at a time. The divergence builds up token by token because each choice shapes the next, not because whole answers are swapped.
- D. Not quite. The MLP stores no answers to retrieve; it is a fuzzy JPEG that nudges embeddings, and it runs the same way every time. The noise acts after the MLP, at the choice, and it spreads because chosen tokens become context.
