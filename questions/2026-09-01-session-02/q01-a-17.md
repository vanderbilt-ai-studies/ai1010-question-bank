**Question:** You type "Hello, world" into a chat. At which stage of the pipeline is that text first replaced by numbers?

- A. Token encodings
- B. Context
- C. Token embeddings
- D. Decoder stacks

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Encoding is the first thing that happens to the context: the text is split into tokens and each token is swapped for its vocabulary number. From that point on the model handles numbers only.
- B. Not quite. Context is your text as you wrote it, together with anything attached and the conversation so far. It is the input, still in words, before any conversion has happened.
- C. Not quite. By the time embeddings are made, the text is already numbers. Embedding turns each vocabulary id into a location in semantic space, which is a second numeric step, not the first.
- D. Not quite. The stacks work on embeddings that are already numeric. If words reached the stacks, the model could do nothing with them.

</details>
