**Question:** Making the model bigger was the field's whole strategy for several years. Why does a much larger model still produce confidently wrong answers?

- A. Because the extra decoder stacks introduce small errors that build up
- B. Because a bigger model is trained on less text, so its coverage is thinner
- C. Because a bigger picture of the world is still a lossy one, and nothing checks for truth
- D. Because larger models lean on the context and ignore what they learned in training

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. Stacks do not accumulate error that way; each one refines the representation a little further. Size changes how much the model knows, not how carefully it computes.
- B. Not quite. The bigger models were trained on far more text, not less. Parameters and training text grew together, which is how the picture got sharper at all.
- C. Correct. Scaling adds resolution, so fewer topics sit in the blurry region. It adds no step that tests an answer, so the model is still producing the most probable continuation, and probable is not the same as true.
- D. Not quite. Both sizes use both sources: attention reads the context and the MLP (multi-layer perceptron) supplies what training left behind. A larger model has more of the second, not less.
