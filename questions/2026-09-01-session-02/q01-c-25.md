**Question:** A friend says a model must have a copy of Wikipedia stored inside it, since it can answer so many of the questions Wikipedia answers. Based on the lecture, what is the more accurate picture?

- A. It compressed everything it read into weights: a lossy picture, not stored text
- B. It contains the text, but zipped, so it can be unpacked exactly whenever it is needed
- C. It stores only the articles people ask about most often
- D. It fetches the relevant article through attention each time it is asked a question

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. The MLP (multi-layer perceptron) holds no articles, only weights shaped by training. That is why the model is sharp on widely covered subjects and blurry on obscure ones, which a stored copy would never be.
- B. Not quite. A zip file is lossless, and the lecture's metaphor is deliberately a JPEG, which is not. If the model could unpack its training text exactly, it would never be fuzzy on rare details, and it is.
- C. Not quite. Nothing is stored article by article, and the model keeps no record of what it was asked. What varies is how sharply a topic is rendered in the weights, set by how much training text covered it.
- D. Not quite. Attention reaches only what is in the context in front of the model. Unless you paste the article in, it is not there to fetch, and the answer comes from the weights instead.
