**Question:** Which of these would raise a model's parameter count?

- A. Adding more decoder layers to the stack
- B. Loading the finished model onto hardware with more memory
- C. Asking it questions that are longer and more detailed
- D. Keeping more of the context in the KV (key/value) cache

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Each extra layer is another copy of the attention and MLP (multi-layer perceptron) matrices, so more layers means more numbers. Widening the MLP or the embedding space does the same thing by a different route.
- B. Not quite. Memory determines whether a model will run, not how many numbers it contains. The count is fixed by the design before training and does not vary with the machine.
- C. Not quite. What you send changes the context, not the model. The weights are the same for every user and every prompt.
- D. Not quite. That cache holds working state from your conversation so the model does not repeat computation over the context; it is not part of what the model is. Parameters are the trained weights, and they are the same numbers before and after any conversation.
