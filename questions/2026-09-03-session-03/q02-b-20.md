**Question:** A friend who has read a little about this tells you that reasoning models contain "a separate reasoning engine alongside the language part, which is why they are slower." Using the lecture's account, how would you correct the picture?

- A. The reasoning engine is real but only runs on requests the model judges to be hard
- B. The reasoning engine is the attention mechanism, which the model leans on more heavily while thinking
- C. The reasoning engine sits after the decoder stacks and inspects the probabilities
- D. There is no second engine -- the same stack generates tokens the model keeps to itself

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. Conceding the engine keeps the mistaken picture. What varies with difficulty is the number of hidden tokens, not which machinery is used.
- B. Not quite. Attention runs for every token in every model in this family, thinking or not. It is not a component that reasoning switches to.
- C. Not quite. Nothing sits between the probabilities and the token beyond ordinary selection. There is no inspecting stage to place there.
- D. Correct. Slowness comes from producing more tokens, not from extra machinery. Every hidden token costs one full pass of the same pipeline, which is why thinking takes time.
