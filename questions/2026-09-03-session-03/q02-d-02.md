**Question:** You run a language model locally on a laptop that has no GPU (graphics processing unit). Roughly what generation speed should you expect?

- A. Roughly what a hosted service gives you, around 60 tokens per second
- B. Thousands of tokens per second, because nothing has to travel over the network
- C. About 100 tokens per second, since laptops and servers run the same code
- D. About 5 tokens per second

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. A hosted service reaches that speed because of the hardware behind it. Strip the specialized hardware away and the same architecture runs more than ten times slower, which is why local models feel like watching someone type.
- B. Not quite. Network travel is not what sets the pace -- generation is. Thousands of tokens per second is what a purpose-built inference chip achieves, and a general-purpose laptop processor is not that.
- C. Not quite. The code really is the same, and that is the point worth noticing: what differs is the hardware doing the arithmetic on enormous weight matrices. That difference costs you more than an order of magnitude.
- D. Correct. Without a GPU the arithmetic falls to a general-purpose processor, and generation crawls at roughly a word every second or two. Running models locally is genuinely useful for privacy and cost, but this is the speed you are trading for it.
