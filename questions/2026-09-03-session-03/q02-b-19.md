**Question:** Who or what decides that a particular request warrants a stretch of thinking?

- A. The interface, which routes hard prompts to a different model
- B. A classifier that scores the prompt for difficulty before the model sees it
- C. The model itself, by producing a think token
- D. The user, who must ask for thinking in the wording of the prompt

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. Routing between models is a separate matter from thinking. The mode described in the lecture opens inside the model that already has your request.
- B. Not quite. No pre-screening stage was described. The decision shows up as a token in the model's own output, which means it happens during generation, not before it.
- C. Correct. The judgement that more work is needed is expressed the only way a model can express anything -- as a generated token, which then opens the mode.
- D. Not quite. You can influence how much thinking is allowed, but you are not the one who triggers the mode on a given turn. The model emits the token that starts it.
