**Question:** What is a reasoning model (also called a thinking model) able to do that an ordinary large language model (LLM) does not do?

- A. Switch into a hidden mode and write tokens to itself first
- B. Search the web for current sources and cite them in the answer
- C. Store your earlier questions permanently so later chats start informed
- D. Run a grammar and fact check over the finished draft before sending it

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. That is the whole of it. The model can decide your request needs more work, produce a stretch of text for its own use, and only then start the reply you see.
- B. Not quite. Looking things up outside itself is a tool, and tools belong to the agent discussion rather than to reasoning. A reasoning model that pauses is producing its own text, not fetching anyone else's.
- C. Not quite. That describes memory, which a plain chat does not have either. Thinking happens inside a single response and vanishes when it is done -- it does not carry across conversations.
- D. Not quite. There is no separate checking stage bolted on at the end. Whatever checking happens is itself just more generated text, produced the same way as everything else and produced before the visible answer starts.
