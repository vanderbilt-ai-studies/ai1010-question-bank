**Question:** An earlier session described a model as a compressed, lossy picture of the world -- a fuzzy JPEG (Joint Photographic Experts Group image file). How does that idea explain the gap between a smaller tier and a larger one?

- A. The smaller tier stores the same picture but retrieves it more slowly.
- B. The smaller tier compresses nothing, so it holds fewer facts perfectly.
- C. The smaller tier keeps a separate database and consults it less often.
- D. The smaller tier is a blurrier copy of the same picture.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. Speed is a real difference between tiers, but it runs the other way, and the JPEG idea is about what survives compression rather than about lookup time.
- B. Not quite. It is the other way round -- a smaller model compresses harder, not less. Compressing harder is exactly what makes the detail go soft.
- C. Not quite. There is no database being consulted. The compression happens in the model's own numbers, which is why lost detail cannot simply be looked back up.
- D. Correct. Squeeze an image into fewer bytes and the broad shapes survive while the fine grain smears. A smaller model holds the same world in fewer numbers, keeping the general and losing the specific.
