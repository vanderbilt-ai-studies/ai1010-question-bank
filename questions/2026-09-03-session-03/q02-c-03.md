**Question:** Apart from choosing a level on the effort menu, what else can you do with thinking in Claude?

- A. Switch thinking off altogether
- B. Carry any unused budget over into your next message
- C. Set a separate budget for each paragraph of the answer
- D. Type a temperature value into the same menu

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. There is an on/off toggle beside the levels, so a task that needs no deliberation can skip the thinking phase entirely. That is useful when you want a fast answer that leans on the model's world knowledge.
- B. Not quite. The budget is a ceiling for the current request, not a balance that accumulates. Unused tokens are simply tokens the model did not need this time.
- C. Not quite. The budget governs the hidden thinking that happens before the reply begins, so it is not divided up across the visible answer. There is one ceiling per request.
- D. Not quite. Temperature is a different control and is not what the effort menu offers. In a chat setup the two things you are choosing are the model and the size of the thinking budget.
