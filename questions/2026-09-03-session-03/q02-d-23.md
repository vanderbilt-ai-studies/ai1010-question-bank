**Question:** The lecture said most people's picture of generative AI stops at one way of using it. Which one, and what does that leave them unaware of?

- A. It stops at chat, so they do not know that agents exist.
- B. It stops at the browser, so they do not know a desktop application exists.
- C. It stops at the default model, so they do not know the tiers can be changed.
- D. It stops at short prompts, so they do not know long documents can be pasted in.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Most people have only ever met a prompt box, so their sense of these systems ends at context in and tokens out. An agent runs the same model with a file system, memory, task tracking, and skills around it, and that is the part they never see.
- B. Not quite. Which window you use matters less than what is around the model. The desktop app is worth installing because it can be pointed at a folder on your machine, and that folder is an agent's file system -- the agent is the point, not the app.
- C. Not quite. Choosing a model is a real control, and one of the two you have in a chat setup. But someone who switches models every day is still working in chat, which is the boundary people do not see past.
- D. Not quite. Getting the right material into context is a genuine skill and the lecture keeps returning to it. Pasting in a long document is still chat, though: context in, tokens out, with nothing around the model.
