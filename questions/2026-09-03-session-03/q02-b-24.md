**Question:** Two large language models (LLMs) are given the same hard prompt. One is a reasoning model, one is not. What difference should you expect in how the response is produced?

- A. The reasoning model consults external sources; the other relies on what it learned
- B. The reasoning model chooses among several answers; the other takes the first one it forms
- C. The reasoning model produces its answer more slowly because each token takes longer
- D. The reasoning model may generate a hidden stretch first; the other answers straight away

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. Consulting outside sources is a tool-use question and belongs to agents. Reasoning is entirely internal -- it is text the model writes for itself.
- B. Not quite. Neither model forms several answers. Both walk forward one token at a time from a probability distribution.
- C. Not quite. A token costs the same either way. The reasoning model is slower because it produces more tokens, most of which you never see.
- D. Correct. That hidden stretch is the only structural difference. Both are running the same pipeline, one token at a time.
