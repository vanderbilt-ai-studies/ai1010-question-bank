**Question:** You want the version of Claude that can work with files on your own computer rather than only inside a browser tab. Which of the products on Claude's apps and extensions page should you install?

- A. Claude for Chrome, because a browser is where the agent needs to run
- B. Claude Code, the CLI (command-line interface), which is the desktop version under another name
- C. Desktop, then download the build for macOS or Windows
- D. Claude for Design, which is the desktop application listed under its product name

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. That extension works inside the browser, which is precisely the setting you are trying to leave. To reach files on your machine you want the application that installs on it.
- B. Not quite. Claude Code is a separate tool that runs in a terminal, and it does come up later in the semester. It is not the desktop application, and it is not what to install this weekend.
- C. Correct. Desktop is the entry to take, and the installer is offered for either operating system. That is the version that can be pointed at a folder on your machine, which is what turns a chat window into something more useful.
- D. Not quite. Claude for Design is its own separate product, not an alias for the desktop app. Take the one labelled Desktop; the others on that page do different jobs.
