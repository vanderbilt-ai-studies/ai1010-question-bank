**Question:** In the lecture's spoken-out-loud analogy, the presenter raised a possible line of answer and then dismissed it as a bad one. What does that dismissal correspond to inside a reasoning model?

- A. More hidden tokens, which then shape what the model generates next
- B. A candidate response being deleted from a shortlist
- C. A weight inside the model being adjusted so it avoids that answer
- D. The model backing up and regenerating from an earlier point

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Rejecting a line is not a special operation -- it is just more text written into the model's own context, and the answer that follows is conditioned on it.
- B. Not quite. There is no shortlist of responses. The model holds one running sequence of tokens, so nothing can be removed from a set that never existed.
- C. Not quite. Weights are fixed by training and do not change while you are talking to the model. A rejected idea leaves its trace only as text in the context, which is what shapes the tokens that follow.
- D. Not quite. Generation only moves forward, one token at a time. A rejected idea stays in the context as written text rather than being rewound and erased.
