**Question:** A classmate says that turning temperature up makes a model slower to answer, because picking unusual words is more work. Why is that wrong?

- A. Producing a token costs the same whichever token it turns out to be
- B. Higher temperature makes the model generate fewer tokens, which cancels the cost
- C. At high temperature the probabilities are computed less carefully
- D. Speed is fixed by the model and the hardware, so no setting can change your wait

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Temperature only changes which token is drawn from probabilities the model has already computed, so the same number of tokens takes about the same time. The dial that does change how long you wait is the thinking budget, because it changes how many tokens get generated at all.
- B. Not quite. Temperature has no say in how many tokens come out; it acts at each step on which one is chosen. Nothing is being cancelled here, because nothing was added in the first place.
- C. Not quite. The model does the same work to produce a distribution over the vocabulary at every step, whatever the temperature. Temperature enters afterwards, when one token is sampled from that distribution.
- D. Not quite. Tokens per second does come from the model and the hardware, but your total wait is that rate multiplied by how many tokens are produced -- which the thinking budget controls. The claim to correct is about temperature specifically, not about every setting.
