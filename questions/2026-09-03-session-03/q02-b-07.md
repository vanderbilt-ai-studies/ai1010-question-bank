**Question:** What changes inside the architecture when a reasoning model switches into thinking mode?

- A. Extra decoder stacks are activated for the duration
- B. An added planning layer runs ahead of the usual pipeline
- C. Nothing -- the same stack produces one token at a time as always
- D. The model widens its embedding space so it can hold more meaning

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. The stack is fixed when the model is built; nothing is switched in or out at run time. What varies is only whether the tokens are shown to you.
- B. Not quite. No new layer appears. The whole point of the lecture's account is that thinking gets its power from ordinary text generation, not from new machinery.
- C. Correct. Context to token encodings to embeddings to decoder stacks to probabilities to a token, over and over. Thinking is that same loop with the output withheld.
- D. Not quite. The width of the embedding space is set before training and never moves afterwards. Thinking adds tokens to the context; it does not add dimensions to anything.

</details>
