**Question:** Why does the weekend exercise ask you to give all four tiers the same problem, rather than a different problem to each?

- A. Because a tier can only be judged on a problem chosen to suit its size.
- B. Because four different problems would cost four times the usage credits.
- C. Because holding the problem fixed shows you what size changes.
- D. Because the four tiers share a cache, so a repeated problem runs faster.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. There is no per-tier problem type. Tiers differ in degree rather than kind, which is exactly why one shared problem is the right test.
- B. Not quite. Cost is a reason to run Fable last, not a reason to reuse the problem. Four different problems would simply leave you with nothing to compare.
- C. Correct. If the problem changes with the model, you cannot tell whether a better answer came from the tier or from an easier question. Fixing it isolates the one thing you are studying.
- D. Not quite. Nothing is shared between tiers that way, and a repeat would not speed anything up. The reason for one problem is comparison, not speed.
