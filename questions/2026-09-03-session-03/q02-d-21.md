**Question:** What does an agent have that a plain chat does not?

- A. A bigger LLM (large language model) inside it, carrying far more parameters than chat uses
- B. A longer context window, letting it take in much more of your prompt at one time
- C. A dedicated inference chip, so that it produces its tokens several times more quickly
- D. A file system it can write to, memory, task tracking, and skills

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. The same model can sit inside either one -- you can converse with an agent just as you would in chat. What is added is around the model, not a bigger model.
- B. Not quite. Context length belongs to the model, and agents do not change it by themselves. What an agent adds is places to put things other than the context window.
- C. Not quite. Speed comes from the hardware a model runs on, and that is a separate question from whether you are in chat or in an agent. An agent is not faster; it is better equipped.
- D. Correct. Chat is context in and tokens out. An agent has the model inside it plus somewhere to keep files, memory that persists, a way of tracking what it is doing, and skills -- which is why it can carry out work rather than only discuss it.
