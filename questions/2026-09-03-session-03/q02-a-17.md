**Question:** You switch from Chat to Cowork in Claude and leave the same model selected. What has changed?

- A. The model is the same; it now has a file system, memory, and task tracking around it
- B. The model is swapped for a larger tier that can handle tools
- C. The model now thinks before every reply, whatever the effort setting
- D. The model generates its answers in parallel rather than one token at a time

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. An agent has the large language model inside it, so you can still converse with it exactly as before. What is added sits around the model -- somewhere to keep files, memory that persists, a way of tracking what it is doing, and skills -- and that is what lets it carry work out rather than only discuss it.
- B. Not quite. Which tier you are running stays your choice in either mode, and an agent works perfectly well with a small one. The step from chat to agent is a step up in equipment, not in model size.
- C. Not quite. Thinking is a separate dial and it stays wherever you put it. Rolling it together with the chat-versus-agent question makes it impossible to say what an agent actually adds.
- D. Not quite. Generation is one token at a time wherever the model runs -- each token has to be produced and fed back in before the next. An agent changes what surrounds the model, not how a token is produced.
