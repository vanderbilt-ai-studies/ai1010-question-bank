**Question:** The weekend exercise asks you to solve one problem with Haiku, Sonnet, Opus, and Fable. What instruction was attached to Fable?

- A. Start with it, so you have a best answer to compare the others against.
- B. Save it for last, because it can eat through your usage.
- C. Skip it entirely unless the first three tiers all fail.
- D. Run it twice, once with thinking turned off.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. A best answer would make a useful yardstick, but running the largest tier first risks spending your usage before you have tried the other three. Finishing the comparison is the point.
- B. Correct. Fable is enormous, so a single run costs far more usage than the tiers below it. Going last means the other three comparisons are already in hand if your limit runs out.
- C. Not quite. The exercise wants all four, not a fallback chain. You are meant to see what the top tier looks like even when a smaller one already did fine -- just not first.
- D. Not quite. Thinking settings are a separate dial from which tier you pick, and they were not what the Fable instruction was about. That instruction concerned the order you run the four in.
