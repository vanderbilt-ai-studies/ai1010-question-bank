**Question:** A student asks whether a reasoning model contains an extra layer of attention and MLP (multi-layer perceptron) whose job is to pick the best of several possible responses. Which description matches the lecture's answer?

- A. The model produces a probability distribution over the next token and steps forward, nothing more
- B. The think token switches on a selection stage that scores the response as it forms
- C. The largest models add such a stage, where the extra compute is worth spending
- D. The model forms several candidate answers side by side and returns the highest-scoring one

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. At the basic level that is all there is: probabilities over the vocabulary, one token taken, then forward again. Thinking looks like deliberation, but it is the same walk with the tokens hidden.
- B. Not quite. The think token opens a mode of hidden generation, not a selection stage. Nothing new is switched on; the same components keep doing what they always do.
- C. Not quite. Size buys wider matrices and more layers of the same kind, not a component of a new kind. Even the largest model here is still generating one token at a time.
- D. Not quite. This is a very natural picture and it is the one the lecture rejected. There are no candidate answers sitting side by side to be scored, because the model never has more than one running sequence.
