**Question:** How should the environmental argument in the lecture change the way you pick a model?

- A. It rules out the largest tiers entirely for any coursework.
- B. It makes the smallest tier that works the sensible start.
- C. It applies only to models you run on your own hardware.
- D. It matters when a model is trained, not when it is used.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. Nothing was ruled out -- the weekend exercise has you use the top tier. The argument is about not reaching for it by habit when a smaller one is already correct.
- B. Correct. Every answer from a large model costs real computation, so always reaching for the biggest one has a running cost. Start small, check the work, step up only when you must.
- C. Not quite. A hosted model runs on someone else's hardware, and that hardware still draws power. Where the machine sits does not change the argument.
- D. Not quite. Training is expensive, but so is every single answer a very large model produces, multiplied across everyone using it. That is the cost you were asked to weigh.
