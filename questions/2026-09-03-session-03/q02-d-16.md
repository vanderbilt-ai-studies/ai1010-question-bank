**Question:** The last line of the transformer pseudocode returns a softmax. What does that softmax give you?

- A. The single token that the model has settled on saying next
- B. The tokens the model produced for itself before answering
- C. A probability for every token in the vocabulary
- D. The weights the model arrived at during training

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. Choosing one token is a further step taken after this. What the pseudocode returns is the full distribution that the choice is then made from.
- B. Not quite. Those are generated by running this whole pseudocode repeatedly, one token at a time. A single pass through it returns something much narrower than a stretch of text.
- C. Correct. One pass through the model ends with a number for each token the model could possibly say next, and that is the token probabilities stage on the pipeline diagram. Everything else in the picture exists to shape that distribution.
- D. Not quite. The weights are the matrices in the pseudocode, fixed before you ever run it. The return value is computed fresh for your context each time.
