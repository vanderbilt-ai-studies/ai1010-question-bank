**Question:** You move from Claude to a different vendor's product and find a completely different set of model names. What should you expect?

- A. Every vendor offers exactly four tiers, matched one to one with Claude's.
- B. A vendor using different names has abandoned the size trade-off.
- C. The names are arbitrary, so a bigger model is not more capable.
- D. The labels differ, but the ladder from small to large is the same.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. What you were promised is that every major lineup is a ladder of sizes -- not that another vendor built the same number of rungs or lined them up with Claude's. The ordering is what repeats.
- B. Not quite. The trade-off is a consequence of building the same architecture bigger, so it does not disappear when a vendor picks different words. Only the labels are local.
- C. Not quite. Within one lineup the bigger model really is the more capable one -- that is what the extra size buys. What is arbitrary is the naming, not the ordering.
- D. Correct. Every major lineup is the same idea under other words, so your judgement transfers: decide which rung the job needs, then find that vendor's name for it.
