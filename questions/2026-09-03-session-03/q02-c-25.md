**Question:** You send exactly the same prompt twice to a reasoning model with temperature turned up. The two replies differ -- and so do the steps the model took to get to them. What explains the difference in the steps, not just in the wording?

- A. The thinking budget is drawn at random for each request
- B. Temperature only comes into play once the visible answer begins
- C. Temperature is in force during the thinking steps as well
- D. The model was swapped for a different tier between the two requests

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. The budget is whatever you set it to and does not vary between requests. Two runs at the same effort setting have the same ceiling.
- B. Not quite. If that were true the reasoning would be identical each time and only the phrasing would move -- which is not what you saw. Thinking is generated the same way the answer is, so the same setting applies to it.
- C. Correct. Thinking is ordinary next-token generation that happens to be hidden, so every thinking step is sampled with your temperature in force. One low-probability token early on sends the model down a different path, and the answer is built on that path.
- D. Not quite. The tier is a dial you set and does not change on its own between messages. Two runs of the same model can still diverge, because the sampling is not deterministic once temperature is up.
