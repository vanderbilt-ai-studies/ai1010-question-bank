**Question:** You are building a notes skill for repeated use. You have one lecture transcript and instructions for processing any lecture. How should you organize them?

- A. Keep the procedure in SKILL.md and the transcript with its task
- B. Put the transcript in SKILL.md and the procedure in the output notes
- C. Put both in the description so selection also supplies every detail
- D. Put both in assets as blank templates for all future lecture tasks

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. The procedure is reusable expertise, while the transcript is the changing input for a particular run.
- B. Not quite. This reverses the roles: source content would replace the reusable instructions, while the method would be buried in one result.
- C. Not quite. The description should summarize outcome and applicability. Full instructions and current source material belong in their own roles.
- D. Not quite. A transcript is a completed source, not a blank template, and procedural instructions belong in the main skill file.
