**Question:** Your skill needs a blank notes layout and a program that repeatedly extracts text. How should you organize these supporting files?

- A. Place the layout in scripts/ and the program in references/
- B. Place the layout in assets/ and the program in scripts/
- C. Place both in the description so they determine the skill's name
- D. Place both among finished outputs for the most recent task run

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. This treats a template as code and executable code as detailed guidance. The file roles point to assets and scripts respectively.
- B. Correct. The layout is a reusable template, while the extraction program performs an executable operation.
- C. Not quite. The description communicates purpose and applicability. It is not where templates and executable routines take the place of supporting files.
- D. Not quite. These files support future runs. Treating them as one run's outputs confuses reusable resources with generated results.

</details>
