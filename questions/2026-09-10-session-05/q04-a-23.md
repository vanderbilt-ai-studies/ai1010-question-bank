**Question:** You run a trained recurrent block four times instead of twice, using the same weights and input. What resource change is most directly supported?

- A. Twice as many independent weights have been learned.
- B. More block computations occur without adding independent weights.
- C. The maximum number of input tokens has doubled.
- D. The number of displayed reasoning tokens must double.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. Applying weights more times does not create additional independent parameters. Learning new weights would require a different operation.
- B. Correct. The shared block is applied twice more. That increases processing work even though the trained parameter set is unchanged.
- C. Not quite. Recurrent depth and context capacity are separate resources. More passes do not establish a larger context window.
- D. Not quite. Hidden processing operates on vectors. More recurrent passes do not require a proportional increase in displayed text.

</details>
