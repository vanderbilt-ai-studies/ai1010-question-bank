**Question:** You test a new skill on an easy source using a stronger model, then test without the skill on a difficult source using a cheaper model. The first output is better. What should you do next?

- A. Conclude that the skill caused the improvement because its output was better
- B. Repeat with matched sources and comparable model settings
- C. Conclude that the stronger model caused every observed difference between outputs
- D. Average the output lengths to estimate how much quality the skill added

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. Task difficulty and model choice changed too, so the observed difference cannot be attributed clearly to the skill.
- B. Correct. A matched comparison reduces competing explanations and lets you examine whether the skill improves the results.
- C. Not quite. The model is one possible influence, but the task and skill also changed. This comparison cannot isolate any one cause.
- D. Not quite. Length is not a substitute for task-specific quality criteria, and averaging it does not remove the mismatched conditions.

</details>
