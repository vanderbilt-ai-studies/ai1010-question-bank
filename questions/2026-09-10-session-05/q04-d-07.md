**Question:** What kinds of inputs should you include in a small initial skill evaluation?

- A. A varied set of easy examples with short, clearly written sources
- B. Representative examples plus at least one difficult case
- C. Repeated runs of the example used to develop the first draft
- D. A collection of the examples that produced the best-looking outputs

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. Variety among easy cases can show some behavior, but difficult inputs are needed to expose weaknesses those cases miss.
- B. Correct. Typical inputs show ordinary behavior, while a difficult case can reveal weaknesses that easy examples hide.
- C. Not quite. Repeating one example can show behavior on that input, but provides narrow evidence about variation across intended tasks.
- D. Not quite. Selecting favorable results can conceal weaknesses. Include representative inputs and a difficult case before judging performance.

</details>
