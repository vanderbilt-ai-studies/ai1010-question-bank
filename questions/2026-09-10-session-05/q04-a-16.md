**Question:** Why can a recurrent block perform extra work without adding independent parameters on each pass?

- A. Extra passes add new layers, each with separately learned weights.
- B. The extra work comes from fitting more input tokens in the context.
- C. Each pass learns improved weights that replace the previous values.
- D. The same learned transformation is applied to successive states.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. Adding independently parameterized layers would increase the parameter count. A recurrent block instead reuses its existing weights on later passes.
- B. Not quite. Context capacity and recurrent computation describe different resources. The same block can process internal representations again without a larger input sequence.
- C. Not quite. Recurrent depth here describes inference with trained weights. The numerical representation changes across passes, rather than a new training update replacing the weights.
- D. Correct. Weight sharing reuses the existing numerical values. More applications can increase computation and latency without increasing the count of independent weights.
