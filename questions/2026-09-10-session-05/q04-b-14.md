**Question:** Why place a long, specialized writing guide in a reference linked from the main procedure?

- A. Its instructions then become the input for every task
- B. It can be opened when that guidance is needed
- C. The guide no longer needs a connection to the procedure
- D. It automatically becomes an executable writing program

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. The guide remains reusable guidance, not the changing source content for each task.
- B. Correct. Staged loading keeps the main procedure focused while making detailed guidance available for relevant steps.
- C. Not quite. A useful reference supports the procedure. Separating it into a file does not remove the need to know when it applies.
- D. Not quite. A referenced document remains guidance. Executable operations belong to code, not prose made into a separate file.

</details>
