**Question:** What does a model's context window describe?

- A. The size of the matrices learned during model training.
- B. The speed at which the model selects output tokens.
- C. The maximum sequence material the model can consider per run.
- D. The count of times a recurrent block is reused per token.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. Matrix sizes help determine parameter count. The context window instead concerns the sequence available during a run.
- B. Not quite. Generation speed measures throughput. Context capacity measures how much sequence material can be considered.
- C. Correct. Context includes supplied and generated material within the system's capacity. It is distinct from parameter count.
- D. Not quite. Recurrent passes describe computation on representations. They do not define the capacity of the context window.

</details>
