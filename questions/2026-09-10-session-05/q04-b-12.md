**Question:** Why does a description that says only "helps with documents" give weak selection guidance?

- A. It omits the entire step-by-step procedure
- B. It fails to include a finished document from each run
- C. It lacks the names of every file in the assets folder
- D. It leaves the intended task too vague

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. A description is supposed to be shorter than the full instructions. The problem is unclear scope, not the absence of every step.
- B. Not quite. Selection guidance should describe recurring work. Appending finished outputs does not repair an unclear task boundary.
- C. Not quite. An inventory of assets does not itself explain the skill's purpose. The description needs a clear outcome and use condition.
- D. Correct. A useful description indicates both the outcome and when the skill applies, so a broad label makes relevance harder to judge.
