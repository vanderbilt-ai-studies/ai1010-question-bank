**Question:** What should a support workflow check after applying a repair?

- A. The affected object and its requested behavior.
- B. The wording of the original repair request alone.
- C. The confidence of the agent that proposed the repair.
- D. The success record of the same repair on a prior case.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Read back what changed and check the behavior the user needed. This establishes more than the fact that an operation was attempted.
- B. Not quite. The request identifies the desired result but does not show the current state. Verification requires observing the affected object.
- C. Not quite. Confidence is generated output, not evidence of the repair. Check the actual saved result and behavior.
- D. Not quite. A documented case helps select a procedure, but its past success does not establish the current result. Read back the object changed in this run.
