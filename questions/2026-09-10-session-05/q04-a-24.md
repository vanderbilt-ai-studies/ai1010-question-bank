**Question:** Two models have equal parameter counts but different maximum context lengths measured in tokens. Which conclusion follows from those facts?

- A. They have different context limits with equal learned parameter counts.
- B. The larger context limit indicates a larger learned parameter set.
- C. The larger context limit establishes faster completion on comparable tasks.
- D. The larger context limit establishes better answers on comparable tasks.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Context capacity and learned parameter count describe different resources. These facts establish a capacity difference, not a universal quality ranking.
- B. Not quite. The stated parameter counts are equal. A longer context window does not by itself establish a larger parameter set.
- C. Not quite. The facts concern capacity, not latency. Processing more text can require additional work, and speed needs separate evidence.
- D. Not quite. A capacity advantage does not guarantee that relevant evidence will be used correctly. Task performance needs to be assessed directly.
