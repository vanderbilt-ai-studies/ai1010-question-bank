**Question:** In a lecture-notes workflow, what role does the transcript of the current lecture play?

- A. The reusable procedure for all future runs
- B. Metadata describing when to select the skill
- C. Input for this particular run
- D. An output generated by the notes procedure

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. A transcript contains lecture content, not the general instructions for turning any suitable transcript into notes.
- B. Not quite. Metadata describes the skill's role. The current transcript supplies the material for one use of it.
- C. Correct. The transcript provides the source content to which the reusable procedure is applied.
- D. Not quite. The notes are the output in this workflow. The transcript is supplied as source material.

</details>
