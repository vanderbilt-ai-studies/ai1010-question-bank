**Question:** You request a particular notes skill by name. The task matches its purpose, but your request lacks the keyword used in its description. How should that affect selection?

- A. The explicit request can still activate the relevant skill
- B. The skill must be ignored until the keyword appears exactly
- C. Every available skill must be activated to resolve the wording
- D. The skill's current outputs must replace its detailed instructions

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. The notes allow users to request a skill directly. Activation is based on relevance rather than a mandatory magic word.
- B. Not quite. This treats activation as a rigid text match. An explicit request for a relevant skill is another way to select it.
- C. Not quite. An explicit request and a matching purpose already identify the relevant procedure. Loading unrelated skills does not resolve a keyword issue.
- D. Not quite. Naming a skill selects its procedure; it does not change prior outputs into the instructions needed for this run.
