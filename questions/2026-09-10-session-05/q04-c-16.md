**Question:** Why should a preferred writing style be distinguished from a record of which file was published?

- A. The writing style is a project fact that expires when a file is published.
- B. The publication record is a preference for what should happen on the next task.
- C. Both records describe stable choices that can be reused without updating.
- D. One can recur across tasks; the other tracks changing project facts.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. A style preference can recur across tasks. Publishing a file changes project state without necessarily changing that preference.
- B. Not quite. A publication record tracks what happened in this project. A recurring preference guides later choices rather than establishing completed operations.
- C. Not quite. Preferences may recur, but a project record tracks changing facts. Reusing stale publication state can misrepresent what has actually been completed.
- D. Correct. A preference may guide many tasks, while project state records current decisions and operations. Maintaining both appropriately helps prevent stale assumptions.
