**Question:** You have a writing procedure that depends on one project's unusual document conventions. You want it available where those conventions apply. Which arrangement fits best?

- A. Make it personal and describe it as suitable for every project
- B. Replace its instructions with the latest finished project document
- C. Remove its description and rely on a distinctive template filename
- D. Keep it as a project-local skill

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. That broad claim would hide its specific assumptions. Personal reuse requires assumptions appropriate to the other projects.
- B. Not quite. An example output does not replace the reusable method that applies the project's conventions.
- C. Not quite. A template filename does not supply the required description or clearly explain when the skill should be selected.
- D. Correct. The procedure's assumptions are tied to that project, which is the use case for project-local scope.

</details>
