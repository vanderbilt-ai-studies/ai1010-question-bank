**Question:** Why can supplying an extra document change an answer without changing the model's learned weights?

- A. The document temporarily replaces the decoder with a search database.
- B. The document increases the number of independently trained layers.
- C. The document changes the input used by the existing transformations.
- D. The document turns its sentences into permanent model parameters.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. A document can inform the decoder through context. Its presence does not imply the model has been replaced by a database.
- B. Not quite. Adding context is not an architectural change. The same model can process different evidence without adding layers.
- C. Correct. Ordinary inference applies trained weights to the current context. New evidence can change representations and next-token probabilities without a weight update.
- D. Not quite. Contextual use and training are different processes. Reading a document in a run does not by itself store it permanently in the weights.

</details>
