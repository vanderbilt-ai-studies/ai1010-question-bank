**Question:** What role does the harness play when an agent requests a file operation?

- A. It invokes an available tool and returns its result.
- B. It treats the generated request as a completed operation.
- C. It stores the learned weights that select the next token.
- D. It makes a successful tool call count as a verified outcome.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. The harness connects a supported request to an available tool. Returning the result lets the model use evidence from the operation.
- B. Not quite. A request expresses an operation to attempt. Execution and checking the outcome still have to happen.
- C. Not quite. Learned parameters belong to the model. The harness provides the operating environment that executes supported tool requests.
- D. Not quite. Executing a tool supplies a result to inspect. You still need to check whether that result meets the task requirement.

</details>
