**Question:** In a lecture-notes workflow, what role do the newly created notes play?

- A. The procedure that replaces future instructions
- B. The metadata used to discover every skill
- C. The source transcript supplied before the run
- D. Output from this particular run

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. One finished set of notes contains a particular lecture's content. It does not replace instructions for processing other lectures.
- B. Not quite. Discovery uses short skill descriptions. Newly created notes are the product of an already selected workflow.
- C. Not quite. The transcript is an input. The newly written notes are what the procedure produces from that input.
- D. Correct. The notes are the result of applying a reusable procedure to the current lecture material.

</details>
