**Question:** Why is a saved skill file insufficient evidence that Skill Creator was used?

- A. The same artifact could be written through a different process
- B. The file confirms the procedure was loaded, but not that testing finished
- C. A saved file proves the procedure ran but conceals its evaluation score
- D. Saving instructions automatically substitutes for comparative evaluation

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. You need execution and file evidence of the requested process, not just an artifact that could have another origin.
- B. Not quite. A file can be written without loading the requested procedure. Check both loaded instructions and completed required work rather than inferring either from the artifact.
- C. Not quite. The file establishes an artifact exists, not that the named process or an evaluation ran.
- D. Not quite. Writing a procedure and testing its effects are different activities. One cannot establish the other.

</details>
