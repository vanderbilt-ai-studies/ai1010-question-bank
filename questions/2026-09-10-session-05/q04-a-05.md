**Question:** In autoregressive generation, what happens to a token after it is selected?

- A. It becomes part of the context for later token choices.
- B. It replaces the trained weights used for later token choices.
- C. It is held apart until the complete answer has been selected.
- D. It supplies a new independent layer for the decoder stack.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Each choice extends the sequence. The growing sequence influences which tokens are likely next.
- B. Not quite. Generated text changes context, not the trained weights during ordinary inference.
- C. Not quite. The answer is generated incrementally. Earlier generated tokens influence later choices before the whole answer exists.
- D. Not quite. Adding a token grows the sequence. It does not add another learned layer to the model.

</details>
