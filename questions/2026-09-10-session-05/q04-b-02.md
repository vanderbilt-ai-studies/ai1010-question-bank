**Question:** Which pair of metadata fields does SKILL.md require?

- A. name and licensing information
- B. name and description
- C. description and compatibility
- D. compatibility and licensing

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. A name is required, but licensing information is optional. The required partner is the description.
- B. Correct. These fields identify the skill and explain its intended use so it can be selected.
- C. Not quite. A description is required, while compatibility information is optional. The skill also needs a name.
- D. Not quite. These can supply useful extra information, but neither replaces the required name and description.

</details>
