**Question:** Where would a reusable blank notes template commonly belong?

- A. The skill's assets/ folder
- B. The skill's executable scripts/ folder
- C. The latest run's completed notes document
- D. The latest run's source transcript file

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Assets can supply reusable inputs such as templates that support the procedure.
- B. Not quite. Scripts provide repeatable code operations. A blank document template is an asset rather than an executable routine.
- C. Not quite. Completed notes are a task output. A template is a reusable starting structure for many outputs.
- D. Not quite. A transcript supplies the content for a particular run. A reusable template instead supplies structure.

</details>
