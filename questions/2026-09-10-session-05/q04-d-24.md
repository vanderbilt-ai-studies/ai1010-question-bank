**Question:** You receive an unfamiliar shared skill that includes executable scripts and asks for file access. What should you do before running it?

- A. Grant the requested access because shared instructions provide a secure sandbox
- B. Read only the output examples because successful examples establish code safety
- C. Review its source, script behavior, and requested access
- D. Assume the scripts are harmless because their folder uses a compatible format

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. Instructions do not create a secure sandbox. Review the source, scripts, and requested access before use.
- B. Not quite. Examples illustrate possible results but do not establish what included code does or where it came from.
- C. Correct. A skill can include ordinary executable code. Understanding its origin and operations helps you assess what you are installing.
- D. Not quite. Format compatibility concerns organization, not the behavior of executable code or the trustworthiness of its source.
