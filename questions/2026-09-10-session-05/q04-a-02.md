**Question:** What is a token embedding in the pipeline studied in this course?

- A. A text definition retrieved for each vocabulary entry.
- B. A probability assigned to the next complete sentence.
- C. A rule that selects which output token comes next.
- D. A numerical vector used to represent a vocabulary item.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. An embedding is a numerical vector, not a dictionary definition retrieved as text.
- B. Not quite. An embedding represents a token before the output stage. Next-token probabilities are calculated after the decoder transformations.
- C. Not quite. Token selection uses the output distribution. Embeddings supply representations for the model to transform.
- D. Correct. A token identifier maps to a vector. The learned geometry can represent relationships between items.

</details>
