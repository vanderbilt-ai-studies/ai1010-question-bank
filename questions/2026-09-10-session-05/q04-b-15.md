**Question:** How should a skill's relevance be judged when a request uses different wording from its description?

- A. Require the description's exact words before selecting the skill
- B. Choose the skill used most recently for any document task
- C. Compare the requested work with the skill's intended purpose
- D. Prefer the broadest skill because it mentions more task types

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. Different wording can express the same task. The notes describe relevance-based activation rather than a mandatory magic word.
- B. Not quite. Recent use does not establish a match to the current request. The procedure's intended outcome and conditions matter.
- C. Correct. A semantic match can make a skill relevant even when the request uses different words from the description.
- D. Not quite. A broad description can obscure task boundaries. Mentioning more categories does not establish the best fit for this request.
