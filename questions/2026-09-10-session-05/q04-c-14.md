**Question:** Why can an agent work with a large project without reading every file into its current context?

- A. Accessible files are already fully represented in every model input.
- B. It can search for and read material relevant to the current step.
- C. Filenames contain enough detail to replace the original source evidence.
- D. A long conversation automatically copies every project file into memory.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. Access means material can be retrieved, not that its contents have already been loaded. The current input may contain only a small selection.
- B. Correct. Useful organization and file tools support selective retrieval. This keeps the current context focused while retaining access to other sources.
- C. Not quite. Names help locate material but do not prove its contents. The agent still needs to open the relevant sources.
- D. Not quite. Conversation history and available files are different sources of information. File contents need to be retrieved through available tools.

</details>
