**Question:** How should you interpret the metaphor that an MLP (multi-layer perceptron) contains world knowledge?

- A. It means factual claims are stored as exact rows with citations.
- B. It highlights learned patterns within a distributed representation.
- C. It means attention contributes no learned information to the model.
- D. It identifies a file that is updated whenever you change the prompt.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. The database interpretation is too literal. Learned weights transform representations and do not guarantee an exact source row for each claim.
- B. Correct. The metaphor points to knowledge learned during training. Knowledge is distributed through the network rather than confined to a literal fact store.
- C. Not quite. The metaphor is not a strict partition of all knowledge. Attention and other learned components also participate in the network's behavior.
- D. Not quite. A prompt changes context during ordinary inference. It does not update a world-knowledge file or retrain the model's weights.
