**Question:** Where would detailed writing guidance commonly belong in a skill folder?

- A. A completed document in the output folder
- B. An executable operation in scripts/
- C. The current transcript in the task workspace
- D. A linked document in references/

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. A finished result shows what one run produced. Detailed reusable guidance is better organized as a reference.
- B. Not quite. Scripts hold code for repeatable operations. Prose guidance about writing belongs in a referenced document.
- C. Not quite. The transcript is the content to process for one task, rather than reusable guidance for writing.
- D. Correct. References hold detailed guidance that can be opened when the main procedure calls for it.

</details>
