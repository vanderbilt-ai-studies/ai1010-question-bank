**Question:** You want a fresh subagent to determine which of two project files contains the accepted revision. How should you prepare its assignment?

- A. Provide only the project name and assume it knows the acceptance decision.
- B. Ask it to complete every remaining project task before comparing the files.
- C. Provide both file locations and the acceptance evidence for comparison.
- D. Tell it to choose the newest-looking filename without opening either file.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. A fresh subagent may not have the decision history. It needs the relevant file locations and evidence of what was accepted.
- B. Not quite. Expanding the task adds unrelated scope. The immediate need is a bounded comparison grounded in the acceptance evidence.
- C. Correct. This supplies the focused context needed for the question. Check the concise result against the sources before using it as project state.
- D. Not quite. A filename can guide retrieval but does not establish accepted content. The subagent needs to read and compare relevant evidence.
