**Question:** What execution resource does a persistent automatic agent need?

- A. A phone connection to a local computer that may be sleeping
- B. An available host on which its operations can run
- C. A saved skill folder on a laptop that is disconnected during scheduled runs
- D. A working installation on a computer used during the initial demonstration

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. Remote control does not make an unavailable local machine an always-on service.
- B. Correct. Persistent operation depends on an execution environment being available when work is triggered.
- C. Not quite. Saved instructions remain available as files, but scheduled operations still need a running, available execution environment.
- D. Not quite. An earlier demonstration shows past availability. Persistent work needs the execution host available when later work is triggered.

</details>
