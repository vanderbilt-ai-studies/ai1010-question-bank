**Question:** What does conversation compaction do during a long task?

- A. Summarizes earlier conversation for a smaller active context.
- B. Copies every available project file into the next model input.
- C. Preserves every original detail in a shorter lossless transcript.
- D. Turns the current project record into a permanent personal preference.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Compaction makes it possible to continue with less conversation in the active input. The summary can omit details, so important original evidence should remain available.
- B. Not quite. Compaction reduces the active conversation through summarization. Reading all project files would instead add material to the input.
- C. Not quite. A summary is selective and can omit details that later matter. You should retain access to the original evidence.
- D. Not quite. Compaction summarizes task history. Changing project facts and recurring personal preferences have different roles.

</details>
