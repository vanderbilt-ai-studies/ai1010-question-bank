**Question:** Why can two interfaces using the same language model support different actions?

- A. Their product labels specify which file operations the model can perform.
- B. Their models execute file operations directly after describing them.
- C. Their harnesses can supply different tools and execution permissions.
- D. Their project names determine the operations built into the model weights.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. A product label is insufficient evidence of available actions. Inspect the actual tools and permissions supplied by the environment.
- B. Not quite. A model generates a request; execution happens through the harness and an available tool. A description alone does not perform the operation.
- C. Correct. Sharing a model does not imply sharing its operating environment. The harness and tools determine which supported requests can actually run.
- D. Not quite. Project selection gives the agent relevant context and a place to work. It does not change model weights to provide file operations.
