**Question:** What does a model parameter count measure?

- A. The number of tokens in the current conversation.
- B. The number of learned numerical values in the model.
- C. The number of intermediate steps in the current reply.
- D. The number of factual statements guaranteed to be correct.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. That is a measure of context length. Parameter count describes the trained model rather than the current conversation.
- B. Correct. Parameters are learned numbers such as weights. Reusing those numbers during inference does not create additional independent parameters.
- C. Not quite. A reply can use more computation with the same parameter set. Steps during inference and learned values are different counts.
- D. Not quite. Parameters are not a catalog of guaranteed facts. A model can generate factual errors regardless of its parameter count.

</details>
