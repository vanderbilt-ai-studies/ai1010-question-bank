**Question:** A daily document-processing skill succeeds in a manual trial. You want it to run unattended. Which preparation best addresses the added demands?

- A. Define triggers, saved progress, checks, and stopping rules
- B. Rely on the single success and repeat the same command continuously
- C. Keep the host online and let each run start without knowledge of prior work
- D. Create a daily trigger and assume missing inputs will resolve themselves

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Also establish required inputs, allowed actions, missing-access behavior, and an available host. Test failure cases before relying on repeated runs.
- B. Not quite. A successful trial leaves failure behavior and repeated-run effects untested. Persistent operation needs explicit operating conditions.
- C. Not quite. Availability is necessary, but saved progress helps later runs resume without duplicating changes.
- D. Not quite. A trigger schedules work but does not define what to do when inputs or access are absent. Specify failure and stopping behavior.
