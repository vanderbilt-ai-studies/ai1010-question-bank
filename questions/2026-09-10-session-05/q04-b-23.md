**Question:** Two skills are both described as "turn text into useful documents," but one makes lecture notes and the other makes meeting summaries. What edit most directly clarifies selection?

- A. Give both skills the same shorter name and description
- B. Move both complete procedures into a single shared description
- C. Describe each output and the kind of source it handles
- D. Add the latest generated document to each scripts folder

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. Making their identifying guidance even more alike preserves the ambiguity instead of explaining their different uses.
- B. Not quite. More procedural detail is not the same as a clear boundary. The description should distinguish purposes without absorbing both full procedures.
- C. Correct. Specific outcomes and use conditions distinguish the two procedures when an agent matches a request to a skill.
- D. Not quite. Generated documents are outputs, not executable routines, and moving them does not clarify when each skill applies.

</details>
