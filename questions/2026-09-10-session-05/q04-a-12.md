**Question:** How can identical prompts produce different responses when the trained weights stay fixed?

- A. Each response trains a different set of weights before starting.
- B. Sampling can choose different tokens and change later context.
- C. Each prompt causes the model to create a different vocabulary.
- D. Attention randomly selects a complete response from a database.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. Ordinary generation uses trained weights. Different samples can produce different text without an additional training step.
- B. Correct. A different early token creates a different continuation context. Later token choices can then follow another path.
- C. Not quite. A new vocabulary is not required for variation. Selection among the existing vocabulary can lead to different responses.
- D. Not quite. Attention combines contextual information. It does not retrieve one complete answer from a response database.

</details>
