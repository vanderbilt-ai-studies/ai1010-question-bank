**Question:** You compare "deposit at the bank" with "picnic on the river bank." Which mechanism helps the representation of "bank" fit these different contexts?

- A. The temperature setting gives the token two permanent definitions.
- B. The token identifier changes the model's trained vocabulary each time.
- C. Attention combines information from the surrounding permitted tokens.
- D. The output sampler looks up both sentences in a reference database.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. Temperature affects sampling. The meaning appropriate to the input is shaped by contextual representations, not permanent definitions set by temperature.
- B. Not quite. The same token can occur in different contexts. A context-sensitive representation does not require retraining the vocabulary.
- C. Correct. Words such as "deposit" or "river" provide different contextual information. Attention helps the representation reflect the usage in each phrase.
- D. Not quite. The sampler chooses from output probabilities. Contextual interpretation happens through model processing rather than a required sentence lookup.
