**Question:** How can you directly change the behavior specified by an existing skill?

- A. Edit its instructions and test the revised procedure
- B. Retrain the model before changing the procedure
- C. Rename the output without changing the instructions
- D. Correct one generated answer without updating the saved skill

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. You can revise the document yourself, then inspect results to see whether the change helped.
- B. Not quite. A skill is editable guidance. Changing its instructions does not require changing the model through training.
- C. Not quite. Changing an output name does not revise the procedure that produces it.
- D. Not quite. Repairing one output can improve that artifact, but it does not change the reusable instructions that govern later runs.

</details>
