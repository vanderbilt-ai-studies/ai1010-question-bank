**Question:** A copied skill is enabled on a second computer, but its extraction step reports that a required library is missing. What should you address first?

- A. Rewrite the output requirements so that extraction is no longer evaluated
- B. Treat the first computer's successful run as proof that the second run worked
- C. Rename the installed skill so that the host treats it as a new procedure
- D. Resolve the library dependency, then rerun and inspect the output

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. The reported failure concerns an execution dependency. Removing a quality check would conceal rather than fix it.
- B. Not quite. Success on the original host does not establish success where the required library is absent.
- C. Not quite. A different name does not supply the missing library that the extraction operation requires.
- D. Correct. The error identifies an environment requirement. After resolving it, verify the procedure on an actual input in that host.

</details>
