**Question:** The lecture argued that the best person to write a skill is someone who is an expert in it. In the context of this assignment, why does that fit?

- A. Because only an expert is permitted to edit a working skill's instructions
- B. Because you are the expert on what you want from the notes, and can say so precisely
- C. Because a skill written by an expert never needs to be revised afterward
- D. Because expertise is needed to operate the coding agent that edits a skill file

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. There is no restriction on who may edit a skill. The point is about the quality of judgment behind the edit, not about permission to make it.
- B. Correct. A skill is only as good as the judgment written into its instructions. A student who knows what makes notes useful to them can state that directly, where an outsider can only guess at it.
- C. Not quite. Skill Creator's own loop of test cases and judged output assumes skills keep getting revised. Expertise makes a better first draft, not a permanent one.
- D. Not quite. Running a coding-capable agent takes no subject-matter expertise, and a purely instructional skill needs no coding agent at all, as the earlier discussion of writing skills in chat established.
