**Question:** A student asked whether you have to explicitly tell an agent to use a particular skill, or whether it happens automatically. What was the answer?

- A. A skill only ever loads when it is explicitly named by its exact file path
- B. Skills always require a human to approve loading them before every single use
- C. It should load automatically when a request matches its name and description
- D. Automatic loading is impossible; every skill must be invoked with a slash command

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. Requiring an exact path would defeat the point of automatic matching. Loading turns on how closely a request matches the skill's name and description, not on typing a location.
- B. Not quite. No per-use approval step was described. Automatic matching is exactly what lets a skill trigger without that kind of gatekeeping on every request.
- C. Correct. That match is the whole reason those two fields stay resident in context. You can also call a skill explicitly, often with a forward-slash command, but recognition is the normal path.
- D. Not quite. Explicit invocation is available as an option, not as the only route. Automatic loading on a close match was described as how a skill is normally reached.
