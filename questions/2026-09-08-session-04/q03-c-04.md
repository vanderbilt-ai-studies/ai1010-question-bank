**Question:** A student uses a GPT-style tool to generate an image, then asks for 'one more small tweak' ten times in a row on the same picture. By the tenth tweak, the image looks quite different from the first version. Which idea from the lecture best explains this drift?

- A. The model's image training data goes stale after repeated edits
- B. Each edit wipes out the model's understanding of the original image and starts over
- C. The projection layer wears down a little each time an image passes through it
- D. Small sampling randomness in the token-by-token image generation compounds a little more with each round

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. Training data does not change during a conversation. The drift the lecture describes comes from something that happens each time an image is generated, not from the training data degrading.
- B. Not quite. If the model started over each time, there would be no continuity at all between edits, which is not what is observed. The drift is gradual, which points to something accumulating rather than resetting.
- C. Not quite. Projection layers belong to the other, Anthropic-style approach in the lecture, and are not described as degrading with use. This mixes up the two approaches the lecture is contrasting.
- D. Correct. Because a picture is produced with the same temperature-like randomness as a sentence, a small random change early in one round's token sequence can shift the result, and repeating this lets those small shifts add up into a visibly different image.
