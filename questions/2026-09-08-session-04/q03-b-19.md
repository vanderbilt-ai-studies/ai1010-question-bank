**Question:** Why does running a representation through the same decoder stack a second time tend to make it more stable, according to the lecture?

- A. A second pass erases the first pass, so the representation starts over.
- B. The second pass uses a different, unrelated stack with entirely fresh weights.
- C. A single pass can leave a representation unstable, and a second pass lets it settle.
- D. The second pass shrinks the embedding space, which is easier to stabilize.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. Looping refines what is already there rather than discarding it. Starting over would throw away the work the first pass did.
- B. Not quite. Reusing the same stack and the same weights is what makes it a loop. Routing to a different stack is just continuing forward through the pipeline.
- C. Correct. One trip through a stack can leave a representation easily pushed around by small changes elsewhere. Running it through the same stack again lets it settle into a more solid state -- enriched, but stable.
- D. Not quite. Nothing about the representation's size changes. The same-sized representation is simply run through the same stack again.

</details>
