**Question:** Per the lecture, what four things does a harness add to a raw model, using the 'no pencils or pens' fix as the frame?

- A. A rubric, a grading skill, a subagent, and a database
- B. A bigger context window, more parameters, faster inference, and a larger vocabulary
- C. A file system, persistent memory, task tracking, and skills
- D. A screenshot loop, a click function, a type function, and a wait function

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. These are specific tools used in the grading demo, not the general list of four things the lecture says a harness supplies to any model.
- B. Not quite. These are properties of model scale and speed, not the externalized capabilities the lecture lists. A harness adds things outside the model, not changes to the model itself.
- C. Correct. These are the four things the lecture lists as what a harness supplies -- exactly the kind of externalized notes and tools the student in the pencils-and-pens analogy is denied.
- D. Not quite. These describe the computer-use loop specifically, not the general list of harness additions. Computer use is one capability a harness can enable, not the four things being asked about here.
