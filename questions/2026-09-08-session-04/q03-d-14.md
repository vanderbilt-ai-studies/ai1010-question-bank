**Question:** What example was given in the lecture of two skills contradicting each other?

- A. A grading skill that grades leniently alongside one that grades harshly
- B. A formatting skill that always specifies orange, alongside a brand skill that bans orange in favor of a fixed palette
- C. A skill written for English output alongside one written for Spanish output
- D. A skill for summarizing video alongside one for summarizing audio, both claiming the same file type

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. Two grading skills with different strictness was not the example given -- the lecture's example was about a formatting choice that one skill requires and another forbids.
- B. Correct. This is the example: a formatting skill that always specifies orange runs into a brand skill that bans orange for a fixed palette, and both are relevant to the same request.
- C. Not quite. A language mismatch between skills is not the example from the lecture -- the conflict described was over a color choice, not over which language to output in.
- D. Not quite. Claiming the same file type is a different kind of problem than the one described. The lecture's example was two skills disagreeing on a formatting rule, not competing over what kind of file each handles.
