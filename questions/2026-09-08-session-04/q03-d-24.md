**Question:** A student with no programming background wants to build a skill that only reformats meeting notes into a fixed template, with no code involved. Based on the lecture, can they do this, and how?

- A. No -- every skill, whatever it does, needs at least some code behind it
- B. Yes, but only after first completing a separate course in programming
- C. No -- only a coding-capable agent such as Claude Code or Codex can create a skill
- D. Yes -- a skill with no code behind it can be written and edited conversationally

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. A code-free skill, such as a pure reformatting skill, was described as needing no code at all, so a universal code requirement contradicts that directly.
- B. Not quite. No coding prerequisite was mentioned. The answer was that programming experience is simply not needed when there is no software behind the skill.
- C. Not quite. A coding-capable agent is recommended when a skill needs real software behind it, such as video-frame extraction. A purely instructional skill does not call for that tool.
- D. Correct. Coding experience matters only when a skill has software to run and test. A fixed reformatting template is pure instruction, so it can be drafted and revised in an ordinary conversation.

</details>
