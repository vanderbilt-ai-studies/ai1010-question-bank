**Question:** Besides turning a solved problem into a new skill, what else can Skill Creator help with, per the lecture?

- A. Automatically translating a skill into every other model provider's proprietary format
- B. Generating test cases for a skill and helping judge whether its output is good, so the skill can be improved over time
- C. Deleting any skill that has not been triggered recently
- D. Merging two contradictory skills into one without any human review

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. Skills are portable because they are just files, not because Skill Creator performs any translation between vendor formats -- no such feature was described.
- B. Correct. This is the iteration loop described: Skill Creator can generate test cases and help judge output quality, so a skill gets revised rather than written once and left alone.
- C. Not quite. Removing a skill by hand was the instructor's own fix for a naming collision, and what was removed was the duplicate of another skill, not one that had gone unused. Either way, Skill Creator does not do it for you.
- D. Not quite. Reconciling contradictory skills was described as something the model does its best at when it hits the conflict, not an automatic merge Skill Creator performs ahead of time.
