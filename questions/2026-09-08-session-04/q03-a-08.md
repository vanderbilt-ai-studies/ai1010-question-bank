**Question:** Which technologies did seat-minder end up using, as described in the notes?

- A. A Ruby on Rails application backed by a MySQL database
- B. JavaScript and Python on Vercel, with a Postgres-compatible database
- C. A no-code drag-and-drop site builder with no database behind it
- D. A shared spreadsheet that every student in the room edits live

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. Rails and MySQL appear nowhere in the notes; the stack described is JavaScript and Python over a Postgres-compatible database.
- B. Correct. That is the stack the notes describe (Neon for the database), and the agent picked it from stated requirements rather than having it dictated up front.
- C. Not quite. The notes describe a real database absorbing many simultaneous check-ins, which is exactly the work a database-free builder could not do.
- D. Not quite. No spreadsheet approach appears in the notes; seat-minder is a hosted web backend with its own database.
