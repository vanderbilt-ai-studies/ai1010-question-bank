**Question:** In the lecture-notes skill, some work is done by its bundled scripts and some by the model's own judgment. Which task belongs to the scripts rather than to the model?

- A. Pulling a frame out of an .mp4 video file at a specific timestamp
- B. Working out what a speaker means by "look here" or "as you can see"
- C. Judging which moments in a session are worth a screenshot at all
- D. Deciding whether the finished notes read as narrative or as expository prose

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. That is ordinary, mechanical software: give it a file and a time and it returns the same image every time. The model's share is deciding which moment matters and reading what the frame shows.
- B. Not quite. Resolving a vague phrase to the thing on screen takes judgment about context, which is the model's half of the pairing. No script can tell which slide "look here" points at.
- C. Not quite. Choosing what deserves a picture is an interpretive decision, so it sits on the model's side. The script only runs once a moment has been chosen for it.
- D. Not quite. Style comes from the skill's written instructions and the model's reading of them -- that is the very instruction the class proposed rewording. Scripts do not weigh in on prose style.
