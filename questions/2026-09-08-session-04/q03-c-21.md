**Question:** A team already runs a strong text-only model in production and wants it to start reading charts and screenshots next quarter, without redoing its pre-training. Which of the two approaches described in the lecture fits that constraint?

- A. Native multimodal training, since images can be folded into the same process at any point
- B. The projection approach, which maps image features into the space the model already learned
- C. Neither, because a text-only model can never be given image understanding
- D. Either one, since the lecture treats the two approaches as interchangeable

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. Native multimodal training is defined by images and text being learned together in one self-supervised process from the very first step. Adding images afterwards is exactly what it does not do, so this route would mean starting the pre-training over.
- B. Correct. That is the sequence the lecture gives: pre-train on text, then add a separate step that projects image features into the representation space the model already holds for words. The trained model is kept and vision is fitted on top of it.
- C. Not quite. The lecture describes this being done in practice. The two approaches differ in when images enter training, not in whether a text-trained model can be given sight at all.
- D. Not quite. The lecture is explicit that these are two genuinely different approaches with different downstream consequences, not two names for one thing. Only one of them adds vision to a model that is already trained.
