**Question:** The instructor said about seat-minder: 'Yes, I used AI to help me solve that problem. Also, yes, technically I created the software. But what I was really doing was using AI to create a solution.' What distinction is this drawing?

- A. Free consumer AI tools versus paid professional ones
- B. Frontend web programming versus backend server programming
- C. Writing the code yourself versus directing an agent to build it
- D. Reasoning models versus non-reasoning models on hard tasks

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. Cost is not the contrast here. The quote is about what role a person plays in a build, not about what the tools charge.
- B. Not quite. That split is a detail of the stack seat-minder ended up with, not the thing this quote sets against itself.
- C. Correct. The quote separates literal authorship of the code from what actually happened: a problem and a set of requirements were specified, and the agent did the engineering that turned them into software.
- D. Not quite. That distinction belongs to the Lab 1 debrief later in the session, not to this quote about how the software came to exist.
