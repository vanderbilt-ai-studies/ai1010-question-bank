**Question:** What second lever for model size did today's session add, beyond width?

- A. More decoder stacks, making the same pipeline longer.
- B. A larger vocabulary of possible output tokens.
- C. A higher maximum context window length.
- D. Replacing the MLP (multi-layer perceptron) with a lookup database.

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Depth is the lever added today: the same attention-then-multi-layer-perceptron block repeated more times, rather than each block being made wider.
- B. Not quite. Vocabulary size sets what tokens the model can emit. It is not one of the two levers the lecture discusses for making a model tier larger.
- C. Not quite. Context window is how much text the model can hold at once, a separate property from how many decoder stacks the pipeline contains.
- D. Not quite. The MLP still carries what the model learned in training, and nothing gets looked up in a database. The lever the lecture adds here is the number of decoder stacks.

</details>
