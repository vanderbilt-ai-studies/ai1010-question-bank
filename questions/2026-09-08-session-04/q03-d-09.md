**Question:** What is Skill Creator, as described in the lecture?

- A. A meta-skill that turns a problem you have already solved into a reusable skill
- B. A blank template you fill in by hand when starting a new skill from scratch
- C. A certification a skill must pass before it can be shared with another user
- D. Another name for the harness that supplies an agent with files, memory, and tasks

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. You solve the problem once, with a strong model and rich context -- ideally including a worked trace of yourself doing the task -- and Skill Creator packages that into something an agent can reuse.
- B. Not quite. Skill Creator starts from work you have already done, not from an empty form. The solved problem, with the context around it, is the raw material it needs.
- C. Not quite. Nothing describes a gatekeeping step. Skill Creator builds a skill and can help test it, but it does not stand between you and handing the skill to someone else.
- D. Not quite. The harness is the surrounding layer that gives a model a file system, memory, task tracking, and skills. Skill Creator is one skill running inside that layer, not the layer itself.
