**Question:** According to the lecture, what is a skill, structurally speaking?

- A. A single system prompt that gets appended to every conversation
- B. A subdirectory of instructions for an agent, often bundled with scripts and reference files
- C. A separate, fine-tuned copy of the underlying model
- D. A plugin that only works if it is written in the same programming language as the harness

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. A system prompt is one flat block of text added to every turn. A skill is the opposite: most of it, including any scripts or reference files, only loads when the task actually calls for it.
- B. Correct. This is close to how the lecture put it: a skill is a subdirectory of instructions for the agent, and it can carry along scripts and reference files that get used only when the task needs them.
- C. Not quite. Fine-tuning changes the model's weights themselves, which takes retraining. A skill changes nothing about the model -- it is just files that tell an existing model how to approach a task.
- D. Not quite. Skills are portable specifically because they are not tied to one programming language or vendor. Requiring a language match would defeat the point of a format any compatible harness can read.
