**Question:** According to the Lab 1 debrief, what capability does a reasoning-capable model have that a non-reasoning model lacks?

- A. The ability to reach the internet for up-to-date information
- B. The ability to generate longer and more detailed answers
- C. The ability to run code in order to check its own answer
- D. The ability to try and compare answers before committing to one

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. External information access is a different capability. The debrief is about what happens inside the model before it commits to an answer.
- B. Not quite. Length is a side effect at most. A reasoning model can be brief; what changes is that it can weigh candidates before it settles.
- C. Not quite. The checking described happens in tokens, in a private scratch space, not by handing the problem to a separate tool that executes it.
- D. Correct. Those tokens build a private scratch space -- restating the problem, trying answers, checking them against each other -- and the capability comes from post-training rather than from any change in how tokens are generated.
