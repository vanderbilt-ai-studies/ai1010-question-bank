**Question:** Getting an agent to operate other applications, such as the 3D tool Blender, points toward which idea named in the lecture?

- A. Replacing screenshots with direct access to the application's source code
- B. Training the model on a dedicated dataset built from one application
- C. Tool-and-connector integrations, formally MCP (Model Context Protocol)
- D. Giving the agent unrestricted administrator access to the operating system

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. This was not the direction of the discussion. The question was about connecting an agent to other software, not about reading or rewriting that software's code.
- B. Not quite. The lecture did not suggest training a model on a single application. What it named was a general way of connecting agents to tools, not app-specific training data.
- C. Correct. The lecture named this formally as MCP (Model Context Protocol) and set it aside as material for a later session rather than explaining it in full at that point.
- D. Not quite. Broad system access was not what was raised. The topic was connecting to specific applications through tools and connectors.
