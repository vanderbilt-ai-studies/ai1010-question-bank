**Question:** According to the lecture, which part of a plain chat session plays the role of the student's own memory in the 'no pencils or pens' analogy?

- A. The model's training data, learned once and fixed before the conversation ever starts
- B. Notes the user happens to keep somewhere outside the chat
- C. The current context window, which has to hold everything the conversation needs
- D. A separate file the chat automatically saves after every message

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. Training data is fixed and does not change during a conversation, so it cannot play the role of something that fills up and runs out the way the analogy describes. The analogy is about the conversation itself, not what the model learned beforehand.
- B. Not quite. The analogy is about what the chat session itself has access to, not what the user personally keeps elsewhere. A chat session cannot read a user's outside notes on its own.
- C. Correct. Just as the student in the analogy can only hold what fits in memory, a chat session can only work with what fits inside its current context window -- there is no external place for it to set anything aside.
- D. Not quite. A plain chat session does not automatically save separate files; that kind of externalized storage is exactly what an agent adds and a chat session lacks, which is the whole point of the analogy.
