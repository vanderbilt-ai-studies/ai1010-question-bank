**Question:** According to the lecture, which kind of skill is reasonable to write or edit directly in chat, without a coding-capable agent?

- A. Any skill whose instructions fit on less than one printed page
- B. Any skill that has already been used successfully at least once
- C. A skill you expect to run only a handful of times before discarding it
- D. A skill that is pure writing or formatting instructions with no code behind it

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. Length was not the deciding factor. A short skill can still depend on code, and a long one may be nothing but prose instructions.
- B. Not quite. A track record does not change what a skill needs for editing. A code-bearing skill still wants a coding-capable agent no matter how well it has run so far.
- C. Not quite. How often you plan to use a skill does not decide where to write it. A throwaway skill can still need real code, and a heavily reused one can be pure instructions.
- D. Correct. With no code to run or test, the whole skill is prose, so it can be drafted and revised conversationally -- the way the class talked through rewording the narrative-versus-expository line.
