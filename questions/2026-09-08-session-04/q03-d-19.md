**Question:** In class, a rewording of the lecture-notes skill was proposed to make it expository rather than narrative, yet afterward the shipped skill still specified "tutorial-style narrative prose." What does this best illustrate?

- A. That the harness automatically reverts any skill edit a student has not approved
- B. That narrative and expository produce identical output, so the wording never mattered
- C. That a skill changes only when someone edits its file, not when a fix is discussed
- D. That a skill rewrites itself automatically after a class discussion about its output

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. No such automatic reversion exists. The rewording was never applied in the first place, which is a different situation from an edit being undone.
- B. Not quite. If the wording made no difference there would have been no complaint that the notes read too much like a story. The whole discussion assumes the word choice changes what comes out.
- C. Correct. The rewording was proposed but never merged, so the old instruction was still the one in force on the next run. Talking through a better instruction does not put it into the skill; editing the file does.
- D. Not quite. Skills do not edit themselves out of a conversation about them. Someone has to change the file, which is exactly the gap this situation exposes.
