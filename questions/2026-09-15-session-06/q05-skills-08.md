**Question:** Which feature of an agent working environment is emphasized when you want help editing skill files?

- A. A larger set of learned parameters
- B. A more detailed written completion claim
- C. A more polished conversation display
- D. Access to the needed files and tools

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. Model size is different from the working environment. The relevant distinction is whether the environment can work with your files and tools.
- B. Not quite. A detailed claim remains a description. File-editing work depends on the environment's ability to use files and tools.
- C. Not quite. Display polish does not establish file-working capability. Choose an environment with the tools and context that fit the work.
- D. Correct. The demonstration distinguished a conversation-centered interaction from an agent environment that can work with files and tools.

</details>
