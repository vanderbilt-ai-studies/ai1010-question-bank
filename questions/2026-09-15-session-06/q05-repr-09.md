**Question:** What does the model program specify in the lecture's distinction between code and learned parameters?

- A. Operations applied to numerical representations
- B. A written rule for each answer the model may give
- C. The correct factual answer to each possible prompt
- D. A record of the text used to train the model

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. The program specifies the computation. Training determines many of the numerical parameter values used in that computation.
- B. Not quite. A particular answer can arise from learned parameters interacting with context. It need not have a corresponding hand-written rule.
- C. Not quite. The computation can generate mistaken claims. Inspectable software does not imply a programmed correct answer for every prompt.
- D. Not quite. The notes distinguish the program from the data and learned numbers. The program describes operations rather than serving as a transcript of training text.

</details>
