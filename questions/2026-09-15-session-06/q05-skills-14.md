**Question:** Why should you ask the agent to identify the actual skill file instead of assuming a folder location?

- A. The skill's location determines whether the model was trained
- B. The location can differ across products and installations
- C. The latest report contains the authoritative skill procedure
- D. The file must be renamed each time its instructions are edited

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. Location concerns where the reusable package is stored. It does not turn editing instructions into training a model.
- B. Correct. The notes describe project and personal skill directories and warn that locations depend on the setup. Identifying the actual file avoids relying on a guessed path.
- C. Not quite. A report is a result, while the skill file holds the procedure. Locate that actual instruction file and its supporting resources.
- D. Not quite. The editing workflow calls for saving with the intended filename. The reason to locate the file is variation in where skills are stored.
