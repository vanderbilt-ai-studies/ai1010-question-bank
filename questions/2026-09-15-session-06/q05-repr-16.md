**Question:** How can two models follow the same broad computation pattern yet differ greatly?

- A. The processing pattern determines the same learned values
- B. The processing pattern lists each model's possible answers
- C. The processing pattern gives a complete account of capability
- D. The parameter arrays differ in size or learned values

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: D**

- A. Not quite. The program specifies operations. Training can produce different values even when the broad computation pattern is similar.
- B. Not quite. A broad algorithm is not a catalogue of responses. Learned values and context also affect the model's behavior.
- C. Not quite. Knowing the operations does not specify the parameter arrays or explain every learned behavior. Similar steps can underlie very different models.
- D. Correct. The same broad operations can use different collections of learned numbers. Knowing the processing pattern does not specify the full model.
