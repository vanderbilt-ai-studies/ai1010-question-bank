**Question:** Your edited instructions look right in a text editor, but the saved file is named SKILL.md.txt. What is the best next step?

- A. Remove the extra extension and assume the file is ready
- B. Check the name and plain-text format, then test
- C. Save it as rich text while giving it the intended name
- D. Confirm the instructions look right and accept the saved copy

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. Fixing the name addresses one concern. The notes also call for confirming plain-text format and testing the intended skill.
- B. Correct. The actual file must have the intended name and format. A test then checks whether the edited instructions function as intended.
- C. Not quite. The correct name does not make rich-text contents plain-text Markdown. Both the name and the format matter.
- D. Not quite. Visual inspection of the wording does not resolve the extra extension or establish the saved format. Check the actual file and test it.
