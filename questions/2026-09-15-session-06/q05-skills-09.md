**Question:** Why should you deliberately choose a project or local folder before asking an agent to revise a skill?

- A. It helps identify which materials belong to the work
- B. It trains the model on every file in that location
- C. It confirms the skill already meets the task criteria
- D. It proves the final file was saved in that location

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. Choosing the working area helps establish the task's relevant materials. The same model can be more useful when its tools and context fit the work.
- B. Not quite. Choosing a working area establishes relevant materials; it does not turn skill editing into model training.
- C. Not quite. A folder identifies materials, not their quality. You still need to compare the procedure and its output with the task criteria.
- D. Not quite. Selecting a folder is preparation for the work. Completion still requires checking that the intended artifact actually exists in the correct place.
