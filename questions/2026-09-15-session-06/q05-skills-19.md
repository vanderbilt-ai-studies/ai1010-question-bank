**Question:** An agent says it assembled your report, results, and revised skill into one file. You open it and find the revised skill is missing. How should you evaluate the work?

- A. As complete because the message lists the required components
- B. As complete because the existing report is readable
- C. As incomplete because required material is missing
- D. As complete because the skill exists elsewhere in the project

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. Listing materials in a message does not establish that they appear in the artifact. Your inspection reveals a missing requirement.
- B. Not quite. Readability is useful, but the required contents also matter. The requested package must include the revised skill.
- C. Correct. Evaluate the artifact against the task. Ask for the omitted skill to be included, then inspect the repaired package.
- D. Not quite. An available source file is not the same as its inclusion in the requested package. Verify the actual deliverable contains the intended materials.
