**Question:** What is an agent harness?

- A. Software coordinating the model's work and tools
- B. The learned numerical parameters inside a model
- C. The vocabulary used to identify tokens in a prompt
- D. The dataset used to adjust a model during training

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: A**

- A. Correct. The harness surrounds the model and manages its work, context, tools, and permissions.
- B. Not quite. Parameters belong to the trained model. The harness is surrounding software that organizes how the model works with tools and context.
- C. Not quite. Vocabulary entries identify tokens for model processing. They do not manage external actions or the surrounding workflow.
- D. Not quite. Training data help determine learned parameters. A harness instead manages the system around a model as it works.

</details>
