**Question:** How should you save a skill instruction file after editing it?

- A. As rich text with visible Markdown headings
- B. As an image with the instruction text visible
- C. As plain-text Markdown with the right name
- D. As a formatted document with a .md label

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: C**

- A. Not quite. Markdown-looking headings do not determine the saved format. Rich-text formatting can prevent the file from functioning as intended.
- B. Not quite. Visible instructions are useful to a reader, but the demonstrated workflow saves the editable instruction file as plain-text Markdown.
- C. Correct. Check both the actual text format and the filename. An added .txt extension or rich-text format can interfere with the intended skill file.
- D. Not quite. Renaming a formatted document does not establish that its contents are plain text. The saved format and the filename both matter.

</details>
