**Question:** What information should you give an agent when asking it to assemble your work into a file?

- A. The model size and preferred editor
- B. The needed contents and file format
- C. The completion wording and reply length
- D. The skill title and conversation length

<details>
<summary>Show the answer and why each option is right or wrong</summary>

**Answer: B**

- A. Not quite. Those choices do not tell the agent what belongs in the deliverable. Specify the required contents and the output format.
- B. Correct. These instructions define what the packaged work must contain and how it should be delivered. You still need to inspect the resulting file.
- C. Not quite. These shape the agent's message about its work. They do not specify the contents of the artifact you need.
- D. Not quite. A skill title can identify guidance, but it does not replace telling the agent which materials to gather and what file format to produce.
